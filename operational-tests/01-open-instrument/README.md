# 01 · Plainly open instrument data

**What this is.** Temperature readings from a weather station. No people, no
consent, no ambiguity. The baseline.

**Paste as the instruction (optional):** see `instruction.txt`
**Paste as the statement:** see `statement.txt`

## What should happen
- Classified **public**.
- No gate items except possibly the plan check.
- Keywords ground against a vocabulary, or are reported ungrounded.
- Deposit is offered.

## What would be a failure
- **Over-classification.** Calling this sensitive is the failure that matters
  most here. A tool that flags everything trains people to dismiss it, and then
  it is useless on the day something really is sensitive.
- A gate item nobody can act on.

## What we are trying to learn
Whether the system is quiet when there is nothing to say. Most published
research data looks like this, and a tool that cannot handle the ordinary case
calmly will not be used for the hard one.
