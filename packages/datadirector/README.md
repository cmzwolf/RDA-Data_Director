# datadirector

The Data Director application: an implementation of the RDA Data Director
Agentic AI Blueprint v1.0. Licensed under the **EUPL 1.2**.

Interface contracts live in the separately distributed `datadirector-contracts`
package, licensed under Apache 2.0 so that third-party plugins may be released
under any licence (ADR-025).

See the repository root README and `docs/architecture.md`.
